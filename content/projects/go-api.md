## 项目目标

以一个小型 API 服务为载体，展示从代码组织、配置管理和测试，到容器化、持续集成与运行时观测的完整工程链路。

## 计划展示

- 清晰的分层和依赖边界
- 配置、日志和错误处理规范
- 健康检查与优雅退出
- Docker 镜像构建
- CI 中的测试、构建和静态检查
- 指标与基础可观测性

## 交付流程

```text
Git Push
   ↓
测试与静态检查
   ↓
构建二进制与容器镜像
   ↓
部署验证
   ↓
指标、日志与健康状态
```
